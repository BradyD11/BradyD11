I like building systems where correctness is enforced, not assumed: type-level invariants, property tests, and tests that prove they can fail.

**Featured work**

- **[fx-ledger](https://github.com/BradyD11/fx-ledger)**: Multi-currency double-entry ledger in Haskell. Currency is a type parameter, so cross-currency math won't compile. STM keeps money conserved under concurrent transfers, and mutation testing shows the concurrency tests catch a lost update.
- **[ledger-cli](https://github.com/BradyD11/ledger-cli)**: Personal finance ledger in Haskell (CLI, plus a Servant + React review screen). Imports are idempotent across overlapping bank exports, and balances reconcile against the bank's own statement. 138 tests.
- **[econometrics](https://github.com/BradyD11/econometrics)**: Fama-French 5-factor model with ML on its residuals, over 60 years of industry portfolios. Walk-forward only, and a machine-checked no-look-ahead test. The honest answer: the signal doesn't survive transaction costs.
- **[django-datatable-view-adv-query](https://github.com/icmanage/django-datatable-view-adv-query)**: Advanced query search for Django datatables, built as an ASU research assistant on a project with IC Manage.
- **[JobAgent](https://github.com/BradyD11/JobAgent)**: Pulls internships from four job boards into one triage list. A Chrome MV3 extension learns your answers and autofills applications across 12 ATS platforms.
